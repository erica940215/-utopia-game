# 烏托邦 Utopia

冰原遠征 × 動物園經營的網頁 3D 遊戲。

- `index.html`：遊戲本體（Three.js）
- `data/*.json`：設定表（物種、物資、裝備、站點、平衡數值）。新增內容只要改這裡
- 存檔：Supabase（Email 登入後跨裝置同步），未登入時存在本機

## 素材來源（皆為 CC0，可免費商用）
- 動物、魚、自然物件：[Quaternius](https://quaternius.com)（經由 [quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase) 取得）
- 火車：[Kenney](https://kenney.nl) Train Kit
- 地形材質：[ambientCG](https://ambientcg.com)
- 物種資料：臺北市立動物園開放資料
